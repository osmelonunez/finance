# Finance v3.8.0 - Operations, optional modules and modular i18n

## Highlights

- `DATABASE_URL` is the single PostgreSQL configuration source; the legacy configuration file and in-app database management have been removed.
- SMTP is configured exclusively through environment variables. Reports keeps SMTP status, delivery tests, and delivery history.
- Accounts support `current`, `savings`, `cash`, and `other` classifications, opening balances, and a consolidated savings total.
- One global display currency applies across the interface without converting historical values.
- Backups run through the internal scheduler and support day-based retention, verification, download, and safe restore.
- Loans and Budgets are optional modules managed from **Management → Modules** with one shared **Save** action.
- Disabling a module hides its navigation and related content, blocks its routes, and preserves all data and history.
- i18n starts its modular structure in `backend/locales/`, while retaining compatibility with all existing keys and calls.

## Upgrade

Configure PostgreSQL with one environment variable:

```yaml
environment:
  DATABASE_URL: postgresql://user:password@server:5432/database
```

Migrations run at startup. `028_optional_loans_module.sql` and `029_optional_budgets_module.sql` enable both modules initially; administrators can change either from **Management → Modules** without data loss.
